# 🎬 Netflix Data Analysis Project

## 📌 Project Description / Purpose
This project focuses on **analyzing Netflix movie data** to uncover insights related to **genres, popularity, voting trends, and yearly movie releases**.  
The objective is to understand **viewer preferences and content trends** using data analysis techniques and visualizations.

---

## 🛠 Tech Stack
- Python
- Pandas
- NumPy
- Matplotlib / Seaborn
- Jupyter Notebook

---

## 📂 Data Source
The dataset consists of Netflix movies with the following attributes:
- Movie title
- Genre
- Popularity score
- Vote count
- Release year

The data was cleaned and preprocessed to handle missing values and ensure accurate analysis.

---

## 🔍 Analysis Questions & Key Findings

### Q1: What is the most frequent genre in the dataset?
- **Drama** is the most frequent genre.
- It appears in **more than 14%** of the dataset among **19 other genres**, indicating a strong preference for drama-based content.

---

### Q2: Which genre has the highest votes?
- **25.5%** of the dataset (approximately **6,520 movies**) falls under popular votes.
- **Drama** again ranks highest, accounting for **over 18.5%** of total popularity votes, showing strong audience engagement.

---

### Q3: What movie has the highest popularity? What is its genre?
- **Spider-Man: No Way Home** has the **highest popularity score** in the dataset.
- Genres include **Action, Adventure, and Science Fiction**.

---

### Q4: What movie has the lowest popularity? What is its genre?
- **The United States, Thread** has the **lowest popularity score**.
- Genres include **Music, Drama, War, Science Fiction, and History**.

---

### Q5: Which year has the highest number of movies released?
- **2020** recorded the **highest number of filmed movies** in the dataset.
